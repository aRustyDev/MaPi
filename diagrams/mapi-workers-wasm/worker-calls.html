Hyperdrive
Bind Hydra, Kratos, and Keto to Postgres with separate database roles. Bind Talos only with the Enterprise Postgres edition. OSS Talos would need durable single-instance SQLite on a validated runtime. MaPi ingress, the adapter, and Oathkeeper reach state through service APIs.
Upstash
Zero bindings in the target. Start with Cloudflare rate limiting at ingress. Add Redis only for a concrete shared-cache or quota requirement.
Workers VPC
Zero VPC Networks in the baseline. For later private compute or an externally hosted AuthZ engine, define a VPC Service per fixed host and port, such as mapi-prod-jobs or mapi-prod-authz, with separate staging targets. Bind it only to the calling Worker. A private Postgres endpoint can have its own VPC Service for Hyperdrive. Use a VPC Network binding if an adapter needs dynamic access to a private network’s routes.
