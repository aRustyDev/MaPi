Where session and token state lives

Kratos Postgres
Identity, browser session record, active or revoked status, and expiry. Kratos is authoritative for session validity.
Hydra Postgres
OAuth clients, Hydra login and consent sessions, and access/refresh grants, chain state and expiry. The proposed port also stores attempt outcomes with each mint transaction. Hydra is authoritative for OAuth token status. Offline JWT verifiers use the signed claims and expiry.
MaPi Durable Object SQLite
Per tenant and Kratos session, store linked issuer and grant references, the fence and its epoch, in-flight attempt IDs, and retryable cleanup intent. Persist these before issuing user-bound tokens or acknowledging a MaPi-initiated revocation. Store references and status; bearer credentials stay with their owning services and clients.
