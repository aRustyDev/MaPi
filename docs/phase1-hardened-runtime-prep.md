## Read-only preflight hardening

The separate prepared preflight now uses the documented paginated `workers/scripts-search` endpoint rather than assuming the Worker-script list is complete. Its inventory helper checks every script and namespace page for complete, consistent pagination metadata, stable totals and page sizes, duplicate rows, and nonempty script, class, owner and namespace identifiers. Generated-name collisions and missing or inconsistent metadata fail closed.
