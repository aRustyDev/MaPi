# Synthetic SQLite schema export

The exporter has since been changed to preserve AUTOINCREMENT sequence state, but that change is **unverified**. Its new native test failed before reaching sequence assertions because the harness tried to read an out-of-range `lastInsertRowid` as a JavaScript number. The tool action to correct the test was aborted before dispatch. The previous passing replay evidence below predates the sequence change; do not rely on it as validation of the current exporter or regenerate the actual fixture from this candidate.

The baseline and fixture generators share `scripts/sqlite-schema-export.mjs` to enumerate exportable schema objects. It excludes the actual ASCII-case-insensitive reserved `sqlite_` prefix. The earlier `LIKE 'sqlite_%'` pattern treated the underscore as a wildcard: a real native SQLite database containing the legal table `sqliteXrecord`, a row, and a view, trigger and index with similar names produced an empty schema selection. The baseline's reconstruction comparison repeated the same filter and therefore could not detect the omission.

Before the sequence change, `node scripts/test-sqlite-schema-export.mjs` passed using separate in-memory native SQLite databases and the extracted fixture exporter. It exported and replayed tables, rows, a view, trigger and index with `sqliteX...` names; verified mixed-case user names and a `__proto__` table; and checked exact signed 64-bit data, BLOBs and valid Unicode including NUL and an apostrophe. It verified that the trigger executed after replay and that SQLite recreated its own `sqlite_sequence` table when the AUTOINCREMENT schema was replayed. It compared the source and reconstructed object definitions and rows. The test did not verify preservation of sequence high-water values.

That test did not run either top-level generator, start a server, touch Woven, or write a generated fixture. The actual pinned fixture and baseline have not been regenerated or revalidated since the sequence change. This is focused native SQLite evidence; it does not establish hosted behavior, arbitrary schema export correctness, or representative Nextgen migration and recovery evidence.
