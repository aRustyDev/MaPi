# Synthetic SQLite schema export

The native sequence replay test now passes after configuring Node SQLite to return the large inserted row ID as a BigInt. `node scripts/test-sqlite-fixture-sequences.mjs` checks deleted high-water rows, a value beyond JavaScript's safe integer range, missing and negative sequence states, quoted names and rejected malformed sequence rows. It compares subsequent generated IDs after replay. This is a synthetic native test, not evidence that the actual pinned fixture or top-level generators have been regenerated.

The baseline and fixture generators share `scripts/sqlite-schema-export.mjs` to enumerate exportable schema objects. It excludes the actual ASCII-case-insensitive reserved `sqlite_` prefix. The earlier `LIKE 'sqlite_%'` pattern treated the underscore as a wildcard: a real native SQLite database containing the legal table `sqliteXrecord`, a row, and a view, trigger and index with similar names produced an empty schema selection. The baseline's reconstruction comparison repeated the same filter and therefore could not detect the omission.

`node scripts/test-sqlite-schema-export.mjs` also passed on the current exporter using separate in-memory native SQLite databases. It exported and replayed tables, rows, a view, trigger and index with `sqliteX...` names; verified mixed-case user names and a `__proto__` table; and checked exact signed 64-bit data, BLOBs and valid Unicode including NUL and an apostrophe. It verified that the trigger executed after replay and that SQLite recreated its own `sqlite_sequence` table when the AUTOINCREMENT schema was replayed. The separate sequence test supplies the high-water checks.

That test did not run either top-level generator, start a server, touch Woven, or write a generated fixture. The actual pinned fixture and baseline have not been regenerated or revalidated since the sequence change. This is focused native SQLite evidence; it does not establish hosted behavior, arbitrary schema export correctness, or representative Nextgen migration and recovery evidence.
