# Relocation sequence metadata bounds

`worker/relocation-sequences.js` implements the existing goose-only sequence policy used by source inspection, destination metadata restore and destination inspection in `worker/relocation-manifest.js`. It accepts zero rows or one nonnegative integer row named `goose_db_version`. It rejects a duplicate or any other row. This does not broaden the reviewed relocation schema or change the separate fixture exporter's AUTOINCREMENT handling.

The SQL query has no sort, limits its result to two rows, and masks a name longer than 32 bytes or a non-integer sequence inside SQLite before the result reaches the JavaScript SQL bridge. Integer results retain the existing exact-integer bridge representation. These constraints bound the rows and individual text payloads returned by this query; they do not establish a bound on SQLite's internal work, total isolate memory, or hosted CPU.

`node scripts/test-relocation-sequence-bounds.mjs` passed in a disposable local workerd Durable Object after local loopback permission was granted. It tests an empty sequence, a valid `goose_db_version` value of 17, duplicate and foreign names, a 4,096-byte name, a 4,096-byte BLOB value, negative, real, text and null values, and 1,024 unexpected entries. A SQL cursor wrapper observed no more than two returned rows and no text cell larger than 32 bytes. Every rejected read rolled back its synthetic checkpoint update and left the synthetic audit count and absence of an export table unchanged. No source, destination, registry, archive, Go owner or Woven object was used.

This narrow local test does not exercise the full pre-freeze or post-freeze manifest, an actual export, a real Nextgen schema, the maximum signed 64-bit value, or hosted operation. It does not establish the unresolved handling of malformed SQLite TEXT or the interrupted fixture-sequence export work. Earlier bridge evidence for exact signed integers remains separate. A selected real-owner candidate still needs the applicable full relocation and hosted evidence before cutover.
