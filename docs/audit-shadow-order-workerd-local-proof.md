# Shadow event ordering: local Workerd diagnostic

`node experiments/audit-snapshot/shadow-order-sort-workerd-test.mjs` passed with exit code 0 on disposable local Workerd and Go 1.26.9. It connected the existing Go external-handle sort and SQLite spool to the experimental shadow view and a new comparator that compares SQLite integer `created_at` values exactly as signed 64-bit nanoseconds, then compares tied IDs in fragments of at most 32 KiB. For 36 synthetic handles, the complete ascending and descending permutations matched a separate Go `time.Time.Compare` plus string-comparison slice oracle. The fixture included signed 64-bit extrema, repeated timestamps, tied TEXT/BLOB IDs, Unicode and long common prefixes. The run made 349 comparisons; the largest returned ID fragment was 32,768 bytes. It also rejected a foreign-project handle and rolled back the spool when a comparison failed after at least one swap.
