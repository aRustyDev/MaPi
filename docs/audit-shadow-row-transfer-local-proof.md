# Audit shadow row transfer: unmounted diagnostic

`experiments/audit-snapshot/shadow-row-transfer.mjs` is an unmounted experiment. It reads one **trusted selected** shadow row under the existing experimental reader lease and emits one encoded frame per call. TEXT and BLOB values are read as raw SQLite byte fragments of at most 64 KiB, INTEGER values as SQLite decimal text, and finite REAL values as the JavaScript number's binary64 representation. Each frame includes its column, offset, type, sequence and preceding digest. A caller-supplied HMAC key protects continuation state bound to the supplied scope, rowid, reader and use. The lifecycle copies the encoded frame inside its synchronous transaction, and the experiment rereads the current frame after asynchronous hashing and signing. A terminal continuation still checks the route, era and lease. The 128 KiB bound applies to a frame, not an event or page.

An initial `node experiments/audit-snapshot/shadow-row-transfer-native-test.mjs` run completed with exit 0, reporting 33 frames. It reconstructed one synthetic 25-column event after source update and deletion, including multi-fragment valid UTF-8 TEXT, BLOB and an integer above 2^53. It checked foreign-project rejection, duplicate first-frame replay, wrong key/scope, tampered continuation and lease release. It used the existing generated baseline and native Node SQLite; it was not a Go handler, Workerd or hosted test.

After that pass, review identified that a caller-owned cursor object could change between asynchronous verification and parsing. The code was changed to copy cursor values before verification and before the first asynchronous scope-hash operation; a test assertion was added. A new run of `node experiments/audit-snapshot/shadow-row-transfer-native-test.mjs` passed for the current source and test, including the cursor-mutation assertion, with 33 frames. Their SHA-256 values were `73967eb1088829f073ec1e26cefd845513f68babfd730416225f50f070d6d03b` and `4aa55db788930aa07505a64ebbdf5d197f0632f271c074ec209d4344e1561f41` respectively. This is a separate completed native test, not a result from the earlier action that was aborted before dispatch.

The experiment does not obtain a row selection from the real Go handler, authenticate the caller or key, establish immutable shadow data, bind the terminal chain to an independent source authority, validate all frames before an HTTP success, or implement lifecycle/recovery/cleanup. Its continuation is authenticated only under the caller-supplied key; a previously scanned frame changed later or a head that changes and returns to the same value is not detected without independently enforced immutability. Rereading the current frame after an asynchronous boundary does not make that reread and the return atomic. Scope processing and the SQLite query itself are not shown to be memory- or CPU-bounded. The callback remains trusted and can access storage outside the lease protocol.

The local SQL API's finite REAL-to-binary64 behavior is not verified in Workerd by this test. Nonfinite REAL values deliberately fail closed and their separately interrupted fidelity work remains open. The test does not establish arbitrary TEXT decoding, full event/error/pagination parity, a complete audit handler, total isolate memory, worker size or hosted behavior. It does not authorize a real cutover or resolve the independent-recovery gate. No Woven or AWS resource was changed.
