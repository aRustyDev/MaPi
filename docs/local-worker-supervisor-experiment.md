# Local worker supervisor experiment

This is an unintegrated, synthetic-only experiment. It does not modify the representative audit fixture's runner or its Worker and it must not be treated as authorization to run either. An attempted edit to add a per-run nonce readiness response to `scripts/large-audit-relocation-test-worker.mjs` was aborted before dispatch with no stated reason; that edit was not retried. The actual fixture still has its original process and readiness behavior, and no Wrangler or representative fixture was run for this experiment.

`scripts/local-worker-supervisor.mjs` starts a child in a detached, supervisor-owned process group. On a parent IPC stop or disconnect, the still-live group leader signals its own group and escalates after a bounded grace period. `scripts/local-worker-harness.mjs` never signals an old process group itself; it reports whether that group disappeared, not whether a descendant escaped into another session. An unexpected supervisor exit, ambiguous process-group check or timeout is not verified cleanup. `verifyLocalReadiness` is an unintegrated helper; the actual Worker has no matching nonce endpoint, so the helper has not established the identity of the real listener.

On November 23, 2026, `node scripts/test-local-worker-supervisor.mjs` exited zero using only synthetic Node processes. The test exercised an owned child and grandchild that ignored SIGTERM, a child startup failure, a deliberately short caller timeout, and an owner IPC disconnect. It checked the known synthetic process IDs and group had disappeared before removing the synthetic test directory. It did not run Wrangler, test the actual runner's SIGINT/SIGTERM behavior, or demonstrate that Wrangler, workerd or any arbitrary descendant stays within the supervisor's group. The helper does not enforce outbound network isolation. The synthetic test's failure path retains its temporary state when cleanup is uncertain.

The actual large runner must not delete its state merely because the original Wrangler leader exits or the supervisor's group disappears: an unobserved descendant could escape the group. Its original port-release/readiness race, inherited environment, raw failure logging, signal behavior and descendant cleanup remain open. Before a real local fixture run, establish a safe implementation and independently verify the relevant process/session membership, readiness identity and cleanup without exposing credentials or targeting unrelated processes.
