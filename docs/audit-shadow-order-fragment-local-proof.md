# Fenced shadow ordering fragments: local evidence

The unmounted `experiments/audit-snapshot/shadow-order-fragment.mjs` reads an event's exact signed-integer timestamp and one ID byte fragment of at most 32 KiB through `withShadowReader`. Each invocation rechecks the route, recovery era, schema, trusted authorization callback and active reader lease; the encoded response remains below the existing 128 KiB frame limit. This supplies a private step for an external sort without the direct shadow read used by the previous sorting diagnostic.

`node experiments/audit-snapshot/shadow-order-fragment-native-test.mjs` passed using native SQLite. It reconstructs a 70,002-byte UTF-8 ID after the source event is deleted, and checks an exact minimum signed timestamp, foreign-project handle, invalid offset, stale generation, rollback of a mutating authorization callback, released lease and frozen source. The focused disposable local Workerd command `node experiments/audit-snapshot/shadow-order-fragment-workerd-test.mjs` also passed: three separate owner calls reconstructed that ID after source deletion and rejected foreign, stale, released and frozen reads. The Workerd test did not exercise a mutating authorization callback. The implementation SHA-256 used by that run was `51791b97786c09f2e9840f14352687e8df6a9bbab35d58d8dc58c27cf8739076`.

This is not a public endpoint, complete comparison, sorting protocol, handler or owner integration. The trusted caller must enforce comparison position and complete ordered iteration; the offset is not an authenticated cursor. The implementation does not establish pinned Go query selection or error semantics, payload integrity, real authorization, cross-object consistency, independently authenticated spool, bounded SQLite-internal memory, total sorting work or hosted behavior. The trusted authorization callback and ordering state remain separate requirements. It does not run or replace the pending handler or interrupted payload-transfer tests. No Woven deployment or AWS resource was changed.
