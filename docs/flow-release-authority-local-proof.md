# Local flow-release authority check

`NextgenApplication.flowRelease` now accepts only action-specific options: none for `status`, `document` and `expectedDeploymentId` for `publish`, and `targetDeploymentId` and `expectedDeploymentId` for `rollback`. It rejects non-object options, arrays and unknown keys before initializing or invoking Go, and constructs the Go input with the owner-derived project ID, origin and admitted action after the allowed options.

The earlier JavaScript constructed the Go input with those authority fields before spreading caller options. The Go flow-release export decodes `projectId`, `origin` and `action` from that input. Source tracing therefore shows that an enumerable option supplied by a caller with a direct Durable Object RPC binding could replace those fields. The HTTP ingress separately constructs a narrow options object from its request body, so this is not evidence that an HTTP caller could supply the overriding keys. A scratch-only attempt to prepare a pre-fix reproduction was aborted before dispatch without a stated reason and was not retried. Pre-fix mutation is an inference from source and has not been demonstrated by this test.

`env -i PATH="$PATH" TMPDIR=/private/tmp node scripts/test-flow-release-authority.mjs` passed on November 23, 2026 in in-process local workerd with loopback permission, ephemeral synthetic SQLite objects, a freshly generated synthetic master key and no Cloudflare credentials. The test constructs its Worker module in memory and has no deploy configuration. It invokes the direct RPC with action, project, origin and case-variant override keys and checks rejection; its typed SQL snapshots compare every selected project, flow-definition, release, deployment and event row before and after each rejection. Normal Go `publish` and `rollback` both completed and added audit events. Mismatched-generation, frozen and post-eviction frozen publication attempts were rejected with those selected rows unchanged. On this local RPC, an object with a non-enumerable `action` arrived as a normal status request without mutation, while an object with an inherited prototype was rejected; these observations are local workerd serialization evidence only.

The selected snapshots do not cover every table or prove a cross-project business-data comparison. The test used the working checkout's prebuilt `worker/generated/phase1-owner.wasm` and symlinked dependencies without freezing them. Its adjacent manifest records MaPi base commit `12555ef02d60d5ee76f328319dc988db75fc6833`, a dirty tree, Nextgen `b0b74cd4a198428ea9b82910c217259ffc62b65c` and Go 1.26.9, but this run did not independently verify that manifest against the bytes or current source. Miniflare's loopback listener does not enforce outbound network isolation. The result is local direct-RPC evidence, not hosted deployment, writer-drain, recovery or final-candidate proof. The user’s real singleton and Woven deployments were not touched.
