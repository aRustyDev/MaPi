# Private external OIDC callback egress proof

Run the private local proof from the repository root:

```sh
GOCACHE=/private/tmp/mapi-isolated-go-cache node scripts/test-idp-callback.mjs
```

The test starts local workerd and a synthetic HTTPS identity provider. Its temporary CA is trusted only by the local test process. The pinned Nextgen Go `idp.NewOIDCClient` and `OIDCClient.Callback` perform discovery, the client-secret-basic/PKCE authorization-code exchange, ID-token signature and issuer/audience/nonce validation against JWKS, and userinfo subject matching. The synthetic provider receives exactly one token request per attempt; tests cover wrong issuer, audience, nonce and userinfo subject, an unexpected JWKS origin, redirects, oversized response bodies, timeouts, competing callbacks and interruption after the one-time token POST.

The Worker reserves a browser-binding hash and callback state in a short SQLite transaction, performs bounded HTTPS fetches outside the transaction, then atomically records the synthetic callback result and audit record. An injected failure after both final writes rolls both back. If the token POST might have been sent and execution stops, the same attempt returns `restart_required` and never automatically reuses the provider code. All transcript data, including the synthetic credential and token response, stays in request memory rather than SQLite. Cloudflare documents that [`transactionSync` callbacks must be synchronous](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/#transactions).

The Go reactor uses an in-memory record/replay transport: each missing request is returned as an intent, JavaScript awaits a fixed allowlisted HTTPS endpoint, then reruns Go with the bounded response transcript. The host checks the exact expected method, path and origin, forbids redirects, and enforces an 8 KiB request and 16 KiB response limit and a 1.5 second per-fetch deadline. The Nextgen egress policy is also exercised by the existing `scripts/test-egress-spike.mjs` lane. Its loopback exception and fixed synthetic endpoint exist only for these local tests; they must never become a production provider allowlist.

This is a private proof, not a shipped external-login route. It does not invoke the full `FlowSSOCallback.Process` or write upstream auth-attempt and mutation-audit records. It uses a synthetic state table, synthetic browser binding and a fake provider, not an upstream deployment, secret-variable resolution, real provider, or browser journey. A production adapter must preserve the pinned revision, upstream state consumption and result/audit semantics, securely generate and verify browser binding, resolve secrets without logging them, establish bounded recovery/expiry for pending records, and fail safely after an ambiguous token POST. An arbitrary tenant-authored provider also requires DNS-rebinding-safe address validation and connection pinning equivalent to Nextgen's egress policy; ordinary Worker `fetch` does not demonstrate that property here. The replay design reruns the Go callback for each outbound response and retains credentials in transient memory; resource cost and behavior under eviction must be measured under hosted limits. No hosted or public endpoint has been deployed.
