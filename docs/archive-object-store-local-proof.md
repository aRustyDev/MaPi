# Archive object writes: local storage primitive

`worker/archive-object-store.js` is an unmounted opaque-object helper. It requests conditional create (`If-None-Match: *`) and compares every returned byte with a bounded copy after a successful write, a failed precondition, or an uncertain acknowledgement. An identical existing value is accepted; different content fails without intentionally overwriting it. Object input and read-back are bounded to a caller-selected maximum no greater than 1 MiB, including all ciphertext, tag and envelope bytes. A caller-supplied abort signal stops waiting for put, get or read; it does not revoke an already-dispatched operation. Callers must retry an uncertain put using the same key and exact ciphertext, then verify the read-back. Error messages do not include object names, contents or upstream exception details.

`node scripts/test-archive-object-store.mjs` passed against a disposable local workerd R2 binding. It covers creation, identical retry, conflicting same-key concurrent writes, exact byte comparison, an injected lost acknowledgement after a completed put, maximum and oversize inputs, malformed key text, an invalid read stream with non-settling cancellation, and a missing object after a failed write. Fault-injection doubles also abort pending puts, gets and reads; prove a late conditional put can commit and is accepted only by an exact retry; and check best-effort cancellation of mismatched or late read bodies. Local loopback permission was required. The temporary R2 data and configuration were local; no Woven resource was accessed.

Cloudflare documents [conditional writes](https://developers.cloudflare.com/r2/api/s3/conditional-operations/) as atomic, but a subsequent delete permits a later conditional creation, and unconditional writes can overwrite an object. This helper does not establish or enforce bucket permissions, retention or permanence. It also does not encrypt, validate a recovery manifest or final seal, provide independent storage or key custody, guarantee that an external operation stops or that a caller's abort signal fires on time, verify a restore, authorize source cleanup, or prove hosted behavior. A later unmounted synthetic archive prototype builds on this helper; see `synthetic-relocation-archive-local-proof.md` for its tests and limitations. The production archive and cutover prerequisite remain unverified.
